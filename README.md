# Народное такси — карта Калининграда

Интерактивная карта на собственных данных PMTiles. Пользователь выбирает точки А и Б, сервер строит автомобильный маршрут через OSRM, а по готовой геометрии едет демонстрационный автомобиль.

Карта и маршрутизатор — разные части. PMTiles только рисует город. Линию маршрута считает OSRM, а не файл карты.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из вывода команды. Карта занимает всё окно.

Скрипты `dev` и `build` используют webpack: MapLibre GL поднимает поток обработки тайлов через `import.meta.url`, а Turbopack в Next.js 16.4 такой адрес пока не собирает. Сам файл потока копируется в `public/workers` командой `postinstall`, чтобы сборщик не подмешивал в него код приложения.

Файл `public/maps/kaliningrad.pmtiles` уже должен лежать в проекте. Приложение его не скачивает и не изменяет. В git он не попадает: это локальный архив.

Скопируйте `.env.example` в `.env.local`, если файла ещё нет:

```bash
OSRM_URL=https://router.project-osrm.org
```

Публичный `router.project-osrm.org` нужен только для разработки. Для постоянной работы подставьте свой сервер OSRM с профилем `driving`. Компоненты карты при этом менять не нужно: браузер ходит в `/api/route`, а адрес OSRM читает только сервер.

## Как пользоваться

1. «Выбрать точку А» и клик по карте. Маркер можно перетащить.
2. Так же укажите точку Б.
3. «Построить маршрут».
4. «Начать поездку», затем пауза, продолжение или повтор.

Маршрут в интерфейсе называется «Оптимальный автомобильный маршрут»: профиль OSRM `driving` выбирает самый быстрый путь по своему весу, а не гарантирует минимум километров.

Координаты везде хранятся как `[долгота, широта]`. В панели для человека сначала показана широта.

## Карта

Стиль собран по слоям этого архива OpenMapTiles 3.14: дороги (`transportation`, `transportation_name`), здания, вода, зелёные зоны, населённые пункты, аэропорт, границы и часть ориентиров. Свойства подписей взяты из метаданных файла. У названий улиц есть `name`, `name:latin` и `ref`, отдельного `name:ru` в этом слое нет. В архиве нет класса `motorway`: главные дороги — `trunk`.

Центр в заголовке PMTiles записан как 20° в.д., 54° с.ш. и лежит вне границ файла. Камера поэтому вписывает реальные границы архива, это сам Калининград.

Подписи используют локальные глифы Noto Sans Regular и Noto Sans Medium в `public/fonts`. Это свободный шрифт SIL Open Font License; файлы диапазонов взяты из [Protomaps basemaps-assets](https://github.com/protomaps/basemaps-assets) и отдаются самим приложением, без платного сервиса. В стиле есть светлая и тёмная палитра, переключатель находится в панели.

Атрибуция OpenStreetMap и OpenMapTiles показана на карте.

## API

`POST /api/route`

```json
{ "from": [20.5, 54.71], "to": [20.55, 54.72] }
```

Ответ содержит GeoJSON `LineString`, расстояние в метрах и время в секундах. Если OSRM недоступен или пути нет, линия не рисуется и числа не подменяются.
